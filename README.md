# Анализ деятельности салона Waves

## О проекте

Салон красоты **Waves** планирует увеличить прибыль и определить потенциальные точки роста бизнеса.

Цель проекта: проанализировать финансовые показатели салона, эффективность проводимых промокампаний и спрос на товары и услуги.

## Задачи

В рамках проекта:

* проведена предобработка данных об операциях салона;
* восстановлены недостающие значения с использованием справочников;
* рассчитаны дополнительные признаки для анализа;
* проанализирована динамика доходов и расходов;
* оценена эффективность промокампаний;
* исследованы популярность и выручка отдельных товаров и услуг;
* подготовлены сводные таблицы и визуализации результатов.

## Инструменты

**Microsoft Excel / Google Sheets**

Формулы и инструменты: `VLOOKUP`, `IF`, `IFNA`, `COUNTIF`, `SUMIF`, сводные таблицы, визуализация данных.

## Основные результаты

Анализ показал рост доходов салона в течение рассматриваемого периода при относительно стабильном уровне расходов.

Наиболее эффективной оказалась промокампания **«Счастливые часы»**: она обеспечила наибольшую дополнительную выручку и прибыль среди проведённых кампаний.

Анализ ассортимента показал, что наибольшую выручку среди услуг приносит **стрижка старшего мастера**, а среди товаров — набор **«шампунь + кондиционер»**. При этом наиболее востребованной услугой по количеству продаж является обычная стрижка.
